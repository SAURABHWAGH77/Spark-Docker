# PySpark & Apache Spark Learning

This repository contains my hands-on learning and practice with **Apache Spark and PySpark** using a Docker-based Spark cluster.

The goal is to understand Spark concepts practically by creating small PySpark applications, running them on a Spark cluster, and observing their execution through the Spark UI.

* PySpark

* Docker

## 🚀 Spark Cluster

The Docker Compose setup contains:

* 1 Spark Master
* 2 Spark Workers
* 2 CPU cores per worker
* 2 GB memory per worker

### Spark UI

After starting the cluster:

**Spark Master UI:**

```text
http://localhost:8080
```

**Spark Application UI:**

```text
http://localhost:4040
```

The Application UI is available while a Spark application is running.

## ▶️ How to Run

### 1. Start the Spark cluster

```bash
docker compose up -d
```

### 2. Submit a PySpark application

Example:

```bash
docker exec -it spark-master /opt/spark/bin/spark-submit \
  --master spark://spark-master:7077 \
  /opt/spark-apps/first_app.py
```

For Windows PowerShell, use the PowerShell line-continuation character `` ` `` instead of `\`, or keep the command on one line.

### 3. Stop the cluster

```bash
docker compose stop
```

To start the stopped containers again:

```bash
docker compose start
```

## 🎯 Learning Approach

Each topic is practiced using a small PySpark application:

```text
Concept
   ↓
Create .py application
   ↓
Run on Docker Spark cluster
   ↓
Observe output
   ↓
Check Spark UI
   ↓
Understand Jobs → Stages → Tasks
   ↓
Document the concept
```

The focus is on understanding **how Spark works internally**, not just writing PySpark syntax.
